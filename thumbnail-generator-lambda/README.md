# Generating Thumbnails from S3 Objects Using AWS Lambda (Container Approach)

This documentation covers how to set up an AWS Lambda function using a **container-based approach** to generate thumbnails from objects (images) stored in an S3 bucket. We'll go through the Lambda container setup, S3 integration, and how to deploy and test the solution.

## Overview

The objective is to create a serverless architecture that automatically generates thumbnails for images uploaded to an S3 bucket. By using **Lambda containers**, we gain flexibility to use custom dependencies and libraries such as **image processing tools** like `Pillow` (Python image processing library), without worrying about Lambda's default runtime limitations.

## Step 1: Use the Existing S3 Bucket

Instead of creating a new S3 bucket, we will use an already existing bucket named `sangh-management`. This bucket will store the original images, and the thumbnails generated by the Lambda function will be placed in a designated folder within the same bucket.

### Folder Structure

- When an image is uploaded to the root folder of the `sangh-management` bucket, the Lambda function will generate a thumbnail and place it in a folder called `thumbnails/` within the same bucket.

## Step 2: Configure Permissions

### 2.1. IAM Role for Lambda

1. **Create an IAM Role**:
   - Go to the IAM Console in AWS.
   - Click on **Roles** and then **Create role**.
   - Choose **Lambda** as the trusted entity.
   - Click **Next: Permissions**.

2. **Attach Policies**:
   - Attach the following policies to the role:
     - **AWSLambdaBasicExecutionRole**: Grants permissions for the Lambda function to write logs to CloudWatch.
     - **AmazonS3ReadOnlyAccess**: Grants the Lambda function permissions to read from the S3 bucket.
     - **Custom Policy**: Create a custom policy to allow the Lambda function to write to the `thumbnails/` folder within the `sangh-management` bucket.

   Here’s an example of a custom policy for writing thumbnails:

   ```json
   {
     "Version": "2012-10-17",
     "Statement": [
       {
         "Effect": "Allow",
         "Action": [
           "s3:PutObject"
         ],
         "Resource": "arn:aws:s3:::sangh-management/thumbnails/*"
       }
     ]
   }
   ```

3. **Finish Creating Role**:
   - Review and create the role. Note the Role ARN for later use in your Lambda function.

### 2.2. S3 Bucket Policy

To allow the Lambda function to read and write objects in the S3 bucket, you may need to add a bucket policy:

1. **Go to the S3 Console**.
2. **Select the `sangh-management` bucket**.
3. **Go to the Permissions tab** and click on **Bucket Policy**.
4. **Add the following policy** (update `YourLambdaExecutionRoleArn` with the ARN of your Lambda execution role):

   ```json
   {
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "Service": "s3.amazonaws.com"
            },
            "Action": "s3:PutObject",
            "Resource": "arn:aws:s3:::sangh-management/*",
            "Condition": {
                "StringEquals": {
                    "AWS:SourceAccount": "061039791346"
                },
                "ArnLike": {
                    "AWS:SourceArn": "arn:aws:s3:::sangh-management"
                }
            }
        },
        {
            "Effect": "Allow",
            "Principal": {
                "Service": "s3.amazonaws.com"
            },
            "Action": "s3:PutObject",
            "Resource": "arn:aws:s3:::sangh-management/*",
            "Condition": {
                "StringEquals": {
                    "AWS:SourceAccount": "061039791346"
                },
                "ArnLike": {
                    "AWS:SourceArn": "arn:aws:s3:::sangh-management"
                }
            }
        }
    ]
}
   ```

## Step 3: Build the Lambda Function as a Container

We will use Docker to build a Lambda container image that processes images and generates thumbnails.

### 3.1 Define the Dockerfile

Create a folder on your local machine called `lambda-thumbnail-generator/` and create a **Dockerfile** inside it.

```dockerfile
# Dockerfile
FROM public.ecr.aws/lambda/python:3.9

# Copy the function code and requirements file
COPY app.py ${LAMBDA_TASK_ROOT}
COPY requirements.txt ${LAMBDA_TASK_ROOT}

# Install the dependencies
RUN pip install -r requirements.txt

# Set the CMD to your handler (app.lambda_handler)
CMD ["app.lambda_handler"]
```

### 3.2 Write the Lambda Code (`app.py`)

In the same `lambda-thumbnail-generator/` directory, create a file called `app.py`. This will be our Lambda function's entry point.

[Link to `app.py` on GitHub](https://github.com/SamyakTechLabs/sangh-management-resources/blob/main/lambda-thumbnail-generator/app.py)

### 3.3 Build and Push the Docker Image to ECR

1. **Build the Docker Image**:
   ```bash
   docker build -t lambda-thumbnail-generator .
   ```
2. **Login to ECR** (Elastic Container Registry) from the CLI:
   ```bash
   aws ecr get-login-password --region <region> | docker login --username AWS --password-stdin <your-account-id>.dkr.ecr.<region>.amazonaws.com
   ```
3. **Create an ECR Repository**:
   - Go to the AWS **ECR Console**.
   - Click **Create Repository**, name it `lambda-thumbnail-generator`, and click **Create**.

4. **Tag and Push the Image to ECR**:
   ```bash
   docker tag lambda-thumbnail-generator:latest <your-account-id>.dkr.ecr.<region>.amazonaws.com/lambda-thumbnail-generator:latest
   docker push <your-account-id>.dkr.ecr.<region>.amazonaws.com/lambda-thumbnail-generator:latest
   ```

## Step 4: Create the Lambda Function

1. Go to the **AWS Lambda Console**.
2. Click **Create Function** and select **Container Image** as the deployment type.
3. Choose **Browse Images** and select the container image you just pushed to ECR.
4. Click **Create Function**.
5. Add the necessary **environment variables** like the S3 bucket name if needed.
	![[Generating Thumbnails from S3 Objects Using AWS Lambda (Container Approach)-1.png]]
	![[Generating Thumbnails from S3 Objects Using AWS Lambda (Container Approach)-2.png]]

### 4.1 Configure S3 as the Event Source

1. In your Lambda function, go to the **Configuration** tab and click **Add Trigger**.
2. Select **S3** as the trigger source.
3. Choose the S3 bucket you created earlier.
4. Set the event type to **Object Created**.
5. **Set the Prefix**: Specify the folders you want to monitor (e.g., `/user/`, `/event/`, etc.) so that the Lambda function triggers only for uploads to those folders.![[Generating Thumbnails from S3 Objects Using AWS Lambda (Container Approach).png]]
6. Save the configuration.

---

## Step 5: Testing the Solution

### 5.1 Upload an Image to the S3 Bucket

- Upload an image file to your S3 bucket in one of the specified folders (e.g., `/user/`). This will trigger the Lambda function to generate a thumbnail.

### 5.2 Verify the Thumbnail

- Go to the **thumbnails/** folder inside your S3 bucket and verify that the thumbnail for the uploaded image has been created.
